# Higher English Grammar — Phrases, Clauses & Analysis

Bilingual (English + বাংলা) offline study companion based on *A Text-Book of Higher English Grammar* (Chapters XXXIII–XXXIX).

## Features
- Chapters: Phrases, Clauses, Sentences, Analysis, Difficulties, Syntax
- Question Bank (Exercises 52–64) with show/hide answers
- English / বাংলা toggle
- Light / dark theme (follows system + manual override)
- Mobile-first, print-friendly, works offline once loaded

## Use
Open `index.html` in any browser, or host on GitHub Pages.

## Deploy (GitHub Pages)
1. Settings → Pages → Deploy from branch → `main` / root
2. Visit `https://pbwsantu-collab.github.io/phrases-clauses-analysis/`

## Note
Chapter notes are condensed for a fast study companion. The Question Bank covers the main exercise types with model answers.
